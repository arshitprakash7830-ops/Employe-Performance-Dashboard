# Employe-Performance-Dashboard
Employee Performance Dashboard analyzes employee productivity, duty hours, and UCC collections. It tracks total and average working hours, collection amounts, first and last slip timings, and supervisor-wise performance. The dashboard helps monitor efficiency, identify trends, and support data-driven decisions.
